# استوديو الراوي الفانتازي - تطبيق بلغة Rust (Rawi Studio Core)

تطبيق ومحرك متكامل ومكتوب بالكامل بلغة **Rust (2021 Edition)** عالي الأداء لكتابة الروايات، وتخطيط خطوط الأحداث الزمنية، وإدارة الكودكس وشبكة الشخصيات، وتوليد خرائط العوالم الفانتازية.

---

## الميزات المتضمنة في كود Rust:

1. **إدارة الرواية والفصول (`models.rs` & `novel_manager.rs`)**:
   - حساب الكلمات، تقدير أزمنة القراءة بدقة، حساب نسب إنجاز الرواية.
   - محرك مقارنة الفصول الجانبي وحساب الفروقات والنسب.
   - إدارة الملاحظات الهامشية والإشارات المرجعية (Bookmarks).

2. **الكودكس وشبكة العلاقات (`codex_manager.rs`)**:
   - إدارة الشخصيات، الأماكن، الأغراض والآثار، فصائل الحكم وأنظمة السحر.
   - بناء رسم بياني لعلاقات الشخصيات (Graph of Relationships).

3. **مولد الخرائط الفانتازية الفائق (`map_generator.rs`)**:
   - توليد 8 نماذج جغرافية قارية وجزرية.
   - توزيع المناخ، الفصول، الرياح السائدة، والبيئات (بما في ذلك البحيرات والبراكين).
   - مصفوفة الدبلوماسية السياسية بين الممالك (حلف، حرب، هدنة، حياد).
   - تصدير الخرائط مباشرة إلى ملفات **SVG** فائقة الجودة بدقة متناهية.

---

## طريقة التشغيل محلياً:

```bash
# الانتقال لمجلد المشروع
cd rust_project

# التشغيل المباشر
cargo run

# البناء بأعلى أداء (Release Mode)
cargo build --release
```
